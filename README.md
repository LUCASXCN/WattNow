# WattNow

用 Mac 这些年试过不少充电监测软件，总觉得都不够全面，没一个真正合我心意的，干脆自己做了个菜单栏小工具 —— WattNow。

## 功能

🔋 **总览一屏全有**
DC 实时输入、系统负载、电池、协商上限、所有端口状态，点开菜单栏就看得到。

📱 **反向供电监测**
Mac 给手机充电也能实时看，多设备同时检测，V×A=W、电量、充满时间全有，全程通知提醒。

📊 **用电统计 & 健康档案**
累计用电量自动算电费，近 7 天柱状图，每个充电器 / 线缆 / 设备都有健康评分，支持 CSV 导出。

📈 **电源监视器**
30 秒到 30 分五档时间窗，功率曲线四线同图，还能弹独立窗口。

🔌 **协商诊断 & 线缆解析**
Mac→线缆→充电器三层找瓶颈，PDO 档位全列出；线缆 E-Marker 身份、速率、载流、EPR 240W、24 针脚全透明。

⚡ **MagSafe & 显示 & 通知 & 四主题**
MagSafe 五触点、显示器带宽诊断、充电事件智能通知，经典 / 极简 / 曜黑 / 奶芙四套主题随心换。

## 技术栈

✒️ 纯 Swift + SwiftUI + Swift Charts，IOKit 直读硬件，本地 JSON，零第三方依赖。

## 系统要求

- Apple Silicon MacBook（M1 及更新）
- macOS 14 及以上
