更新日志

WattNow v1.2 · 2026-09-06

新增

  • 系统级原生充电上限：总览页新增「充电限制」卡片，滑块可选 80% / 85% / 90% / 95% / 100% 五档（默认 80%），一键导入系统快捷指令即可使用。
  • 借助快捷指令（Shortcuts）实现：调用 macOS 26.4 新增的系统 SetBatteryChargeLimit 动作，写入的就是「系统设置 > 电池」里那同一个上限值。
  • 真正的原生式体验：到达阈值后适配器保持在线、只掐电池充电，不是断适配器掉电再回充；无需 root、无需后台助手、不经过任何网络。
  • 设置后自动通过 pmset -g battlimit 回读确认生效，卡片实时显示系统当前实际上限。

修复 / 优化

  • 彻底移除 Python 依赖：原 iPhone 电池读取依赖 /usr/bin/python3，未装 Xcode 命令行工具的用户打开软件会触发系统「正在下载软件」弹窗。现改用 Swift 原生 SecureTransport TLS 重写，App 包内零 .py 文件，打开即用、不再弹下载。
  • 修复 MagSafe 图标不显示：powerplug / powerplug.fill 符号在部分机型渲染异常，全部替换为 cable.connector.horizontal（MagSafe 横向接头）与 bolt.fill（供电 / 充电器）。

安装说明

1

下载并解压：点击上方按钮下载 WattNow.zip，双击解压得到 WattNow.app。

2

拖入应用程序：将 WattNow.app 拖到「应用程序」文件夹。

3

首次打开：右键 WattNow.app → 选择「打开」，在弹窗中再次点击「打开」即可（因未经过公证，首次需右键打开）。

4

开始使用：软件启动后会出现在菜单栏右上角，点击图标即可展开面板。

5

开启充电限制（可选，需 macOS 26.4+）：在总览页「充电限制」卡片点「一键导入快捷指令」，在弹出的预览里点「添加快捷指令」即可，之后拖动滑块选上限、点「确认」生效。
